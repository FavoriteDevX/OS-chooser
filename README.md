# OS Chooser 🖥️ 🤔

An interactive, web-based quiz designed to help users decide which **Operating System (OS)** and **exact variant/distro** best suits their needs, budget, and personality.

##🌐 Live Demo Here: https://oschooserlol.vercel.app/

---

## ✨ Features

- **Honest & Fun Questionnaire:** Evaluates budget ("Are you rich?"), terminal comfort, gaming habits, privacy concerns, and daily workflow.
- **Smart Scoring Engine:** Weighs user answers across 6 major OS ecosystems and displays both the #1 match and the runner-up.
- **Specific Variants & Editions:** Goes beyond generic recommendations by suggesting exact editions (e.g., *Linux Mint*, *Arch Linux*, *Windows 11 LTSC*, *AtlasOS*, *macOS Sequoia*, *ChromeOS Flex*, *FreeBSD*).
- **Zero-Build Architecture:** Built with vanilla HTML5, CSS3, and JavaScript—no heavy frameworks or build steps required.

---

## 🖥️ Supported Operating Systems

| OS Family | Recommended Variants Included |
| :--- | :--- |
| **macOS** | macOS Sequoia (MacBook Air/Pro), macOS Studio |
| **Windows** | Windows 11 Home/Pro, Windows 11 LTSC, AtlasOS / Tiny11 |
| **Linux (User-Friendly)** | Linux Mint, Pop!_OS, Ubuntu / Zorin OS |
| **Linux (Power User)** | Arch Linux, Fedora Workstation, NixOS |
| **ChromeOS** | ChromeOS (Chromebook), ChromeOS Flex |
| **BSD / Unix** | FreeBSD, OpenBSD |

## 🚀 How to Run or Contribute

1. **Clone or fork** this repository:
   ```bash
   git clone https://github.com
   ```
2. Open `index.html` in any web browser—no `npm install` or build tools needed!
3. Want to add more questions or OS variants? Edit the `osProfiles` and `questions` objects inside `index.html` and submit a Pull Request.
